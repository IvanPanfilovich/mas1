# Compatibility and compliance

| Surface | Portable workflow | Exact canonical v6.1 |
| --- | --- | --- |
| Codex desktop / CLI | Project roles and installer; parent model inherited | Conditional on the original model routes, permissions, independent contexts and required evidence actually being available |
| Claude Code | Native Markdown roles and installer | A Claude-only runtime cannot satisfy the original OpenAI model identities |
| ChatGPT / ChatGPT Work | Paste/attach portable prompt; tool and subagent support is client/account dependent | Only if every required route and evidence source is actually exposed; no generic compliance promise |
| Claude conversation | Paste/attach portable prompt; capabilities depend on client | Claude-only use cannot satisfy original model-specific gates |

The canonical source is preserved at `prompts/MAS1-v6.1-canonical.md`. Public default integrations use `MAS1-portable/1`. The adaptation preserves requirements, proportional assurance, bounded delegation, ownership, causal repair, stable-basis verification and honest readiness reporting. It changes model selection, permits portable prose ledgers, and has a provider-neutral independent escalation rule. These changes are substantive and are not canonical v6.1 compliance.

The original no-prework executor requires GPT-5.6 Sol/xhigh. Its first complete Standard artifact review and repair closure require verified Terra/high routing; its second confirmed lifetime escape requires runtime-verified Astra adjudication with no Sol fallback for that gate. Editing a profile to a different model does not satisfy these requirements.

The `tools/` validator intentionally retains original model checks and the release-controlled invalidated-cutover catalogue. Do not weaken it to make portable results pass. Do not fabricate model, token, review, or adoption evidence. Prompt adoption is separate from model identity. Browser couriers and authenticated ChatGPT Web execution remain unsupported by canonical v6.1.

The optional Polishing Prompt 1 file is preserved as a reference. It is not installed by the portable installer and does not automatically become portable; inspect its original MAS1 dependencies before invoking it.

Adapters have automated format and installation checks. No live end-to-end Claude, ChatGPT, or Codex orchestration run is claimed by this release. Account model availability is not established by package tests.
